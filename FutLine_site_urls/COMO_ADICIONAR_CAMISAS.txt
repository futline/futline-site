COMO CADASTRAR CAMISAS NA FUTLINE

No index.html, procure:

const shirts = {
  retro: [],
  jogador: [],
  torcedor: []
};

Adicione a camisa dentro da categoria desejada.

Exemplo:

retro: [
  {
    id: "brasil-2002",
    name: "Camisa Brasil 2002",
    image: "https://exemplo.com/brasil-2002.png",
    price: 179.90
  }
],

Os campos são:
- id: identificador único da camisa
- name: nome mostrado abaixo da imagem
- image: URL completa da imagem
- price: preço mostrado abaixo da imagem

NÃO precisa colocar "imagens/" nem usar uma pasta local.
A imagem será carregada diretamente pela URL informada.

O site cria automaticamente:
- imagem
- nome
- preço
- botão Adicionar ao carrinho

O carrinho continua enviando as camisas selecionadas para o WhatsApp.
